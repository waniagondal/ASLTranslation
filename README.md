A pipeline for the recognition of American Sign Language, and conversion into spoken word. The core recognition module is grounded in a supervised deep learning approach using Multilayer Perceptron Architecture (MLP), with batch normalization, dropout regularization, and ReLU activation. The model is optimized with the Adam algorithm and trained using cross-entropy loss, achieving an accuracy of 92%. The sequential letter predictions are combined to form words and sentences, which are able to be converted into speech using a text-to-speech (TTS) engine with customizable voice parameters. Bidirectional communication is enabled through a spoken language transcription module. The non-machine learning components are implemented in Java, using Java Swing for the UI. Clean Architecture (CA) principles were followed, where high-level modules are decoupled from low-level implementation details.
